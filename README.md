# Persi Leveling

A project inspired by Solo Leveling focused on turning real life progress into an RPG style system.

The idea is to create an application where real life tasks generate XP, levels, ranks, and character progression  making life feel like a game.

---

## Goal

This project is being developed as my main portfolio project and also as a way to improve my programming skills.

I want to build something visually impressive, functional, and motivating for users.

## Planned Features

XP system
Level system
Daily quests
Rank system
Streak tracking
Interactive dashboard
Login and progress saving
Achievements and badges
Level up animations
RPG/anime inspired interface

## Technologies

JavaScript
React
Next.js
TailwindCSS
Node.js
Supabase / PostgreSQL
